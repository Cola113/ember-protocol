## 4. 索引面板（钉选 / Synthesis / 真相状态机）

四态：`unknown` → `encountered`（至少 1 条必选命题）→ `suspected`（必选命题齐、未综合成功）→ `believed`。

| ID | 步骤 | 预期 | 结果 | 记录 |
|----|------|------|------|------|
| IX-01 | 无命题时打开 INDEX | 6 条真相均为 unknown；综合按钮不可用或失败 | ☐ | |
| IX-02 | Esc 或 RETURN TO VIEW | 关索引回星系；焦点不丢在不可见层 | ☐ | |
| IX-03 | 只收集 T1 第一条 | T1 = encountered；T2+ 仍 unknown | ☐ | |
| IX-04 | T1 两条都齐、未综合 | T1 = suspected | ☐ | |
| IX-05 | 命题齐但假说乱打（避开 ledger `keywords`） | verdict 非 believed；T1 仍 suspected | ☐ | |
| IX-06 | 假说含至少一个关键词（如「引导程序」「Bootstrap」）或使用草稿假说 | T1 → believed；全息解锁层；星图出现窑 + 果园 | ☐ | |
| IX-07 | 缺命题时硬点综合 | 拒绝 believed；反馈列出缺的命题 ID | ☐ | |
| IX-08 | 已 believed 的真相再综合 | 不可重复写入；不重复弹解锁层 | ☐ | |
| IX-09 | 钉选：把命题插入假说 | 文本出现 `[Proposition.Id]`；可多条 | ☐ | |
| IX-10 | 切换「命题综合台 / 推理图谱」 | 图谱展示已收集命题与真相状态；不丢假说草稿（若保留则记录实际行为） | ☐ | |
| IX-11 | T2：只做窑、不做果园 | T2 停在 encountered；窑+果园都做完才 suspected | ☐ | |
| IX-12 | 按链做完 T1–T3 | 解锁顺序符合 §2：T1→窑果园，T2→咏井针，T3→总账髓 | ☐ | |
| IX-13 | Tab 在索引内循环 | 焦点困在对话框内，不会 Tab 到背后星图 | ☐ | |
| IX-14 | 顶栏 BELIEVED n / 6 | 与真实 believed 数一致 | ☐ | |

Curator 现为 stub：过关条件 = 必选命题齐 **且** 假说命中 ≥1 个关键词。P2 真 AI 接线后要重跑 IX-05/06。

| ID | 步骤 | 预期 | 结果 | 记录 |
|----|------|------|------|------|

| SV-04 | 读 slot_1 | 命题/真相/已完成热点/倒计时恢复；**进入星系**（不是开场、不是戏台正中） | ☐ | |
| SV-05 | 读档后打开 INDEX | believed 与命题和存盘一致 | ☐ | |
| SV-06 | 新游戏 | 内存进度清零、回到开场；**不要**默默删掉其它槽（除非 UI 明示） | ☐ | |
| SV-07 | 新游戏后再读 slot_1 | 仍是旧进度 | ☐ | |

| SV-11 | 删档（若有删除按钮） | 该槽变空；其它槽保留 | ☐ | |

## 6. 结局（三分支 / 倒计时门槛 / 统计）

**入场条件（实现）**：6 条真相全部 believed（T1–T5 + THidden）。Overwrite 额外：剩余 ≤ 25%（≤ 600 s，HUD &lt; 10:00）。倒计时到 0 **不**自动结束。

|----|------|------|------|------|
